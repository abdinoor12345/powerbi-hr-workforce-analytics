# Reports Folder

This folder contains the Power BI report file(s).

## Files

- `HR_Analytics_Dashboard.pbix` - Main dashboard file

## How to Use

1. Download the `.pbix` file
2. Open with Power BI Desktop
3. Refresh data if needed (Home → Refresh)
4. Explore the dashboard!

## Requirements

- Power BI Desktop (latest version recommended)
- Download from: https://powerbi.microsoft.com/desktop/

## File Size Note

If the `.pbix` file is not present in this repository (due to size limits), you can:
1. Create your own using the documentation provided
2. Contact the repository owner for access
3. Use the sample data in the `data/` folder to build your own

## Publishing to Power BI Service

To publish this dashboard online:

1. Open the `.pbix` file in Power BI Desktop
2. Click **Publish** in the Home ribbon
3. Select your workspace
4. Share the link with stakeholders

## Data Refresh

The dashboard uses the CSV file from the `data/` folder. To refresh:

1. Home → Transform Data
2. Update the source file path if needed
3. Close & Apply
4. Save the `.pbix` file
